# 04_単体テスト仕様書

## 1. 方針

単体テストは、Handler、Service、Repository、AI Harness、URL抽出、認証、Reactコンポーネントを個別に検証する。フェーズ2のテストコード名にはテストIDを含める。

## 2. Backend単体テスト

| ID | 対象 | 観点 | 期待結果 |
| --- | --- | --- | --- |
| UT-AUTH-001 | Login Handler | 正しいパスワード | 200とCookieを返す |
| UT-AUTH-002 | Login Handler | 誤ったパスワード | 401を返す |
| UT-AUTH-003 | Auth Middleware | Cookieなし | 401を返す |
| UT-NOTE-001 | Note Handler | 正常な作成JSON | Serviceが呼ばれ201を返す |
| UT-NOTE-002 | Note Handler | 空入力 | 400を返す |
| UT-NOTE-003 | Note Handler | JSON不正 | 400を返す |
| UT-NOTE-004 | Note Service | H1タイトルあり | H1をtitleに採用する |
| UT-NOTE-005 | Note Service | H1タイトルなしAI成功 | AI titleを採用する |
| UT-NOTE-006 | Note Service | AI失敗 | `無題`または明示タイトルで保存する |
| UT-NOTE-007 | Note Service | 本文保存 | 本文を省略しない |
| UT-URL-001 | URL Extractor | URLなし | 空配列を返す |
| UT-URL-002 | URL Extractor | 複数URL | 入力内URLのみを順序維持で返す |
| UT-URL-003 | URL Extractor | AI追加URL | 保存対象にしない設計を確認する |
| UT-AI-001 | AI Harness | 正常JSON | title/contentを返す |
| UT-AI-002 | AI Harness | 不正JSON | エラーを返す |
| UT-AI-003 | AI Harness | タイムアウト | エラーを返しServiceでフォールバック可能 |
| UT-REPO-001 | Repository | Create | `BOOK_notes`へ保存するSQLを実行する |
| UT-REPO-002 | Repository | Search | title/contentに対してILIKE検索する |
| UT-REPO-003 | Repository | Delete | 対象なしはnot foundとして扱う |

## 3. Frontend単体テスト

| ID | 対象 | 観点 | 期待結果 |
| --- | --- | --- | --- |
| UT-FE-001 | PasswordGate | 入力送信 | `/api/login`へfetchする |
| UT-FE-002 | NoteEditor | 空入力 | 送信を抑止する |
| UT-FE-003 | NoteEditor | 正常入力 | `/api/notes`へraw_textを送る |
| UT-FE-004 | NoteList | 一覧表示 | title、created_at、preview、URL有無を表示する |
| UT-FE-005 | NoteItem | 編集 | PUTリクエストを発行する |
| UT-FE-006 | NoteItem | 削除 | DELETEリクエストを発行する |
| UT-FE-007 | SearchBox | 検索 | q付きGETを発行する |
| UT-FE-008 | MarkdownPreview | プレビュー | 表示用にMarkdownを描画し保存内容は変更しない |

## 4. 追跡方法

Goテスト関数名の例: `TestNoteServiceCreate_UT_NOTE_006`。Reactテスト名にも`UT-FE-001`のようにIDを含める。
